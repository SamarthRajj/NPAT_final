NPAT

Name · Place · Animal · Thing — real-time multiplayer

A realtime browser game built with Node.js, Express, Socket.IO, and JWT-authenticated WebSockets. Create or join a room, play 3 rounds with friends, and view the final server-calculated results.

How it works

  1. Enter a username and connect.
  2. Create a room or join an existing one with a room code.
  3. Wait in the lobby until at least 2 players have joined.
  4. The room creator starts the game and advances rounds.
  5. Submit a valid answer each round and view final scores.
